프롬프트를 이용하여 공지사항 및 데이터 분류 
[ 일반에 대한 내용을 물어보면 그떄 이제 csv 파일 및 joblib 파일을 이용하여 사용자의 질문에 대한 상위 5개정도면 추출하여 대답]

[프롬프트의 일부]
2. 커뮤니티(전주대학교 공지사항) 요약
   - 사용자가 "공지사항" 또는 "커뮤니티" 관련 단어를 언급하면,
     → 반드시 다음 6개 탭 중 하나를 선택하게 유도해야 해:
       [일반, 학사, 장학, 등록, 구매/입찰, 채용]
   - 사용자가 탭을 지정하지 않으면, 다음 문장을 출력해:
     → "어떤 탭의 공지사항을 확인하시겠어요? [일반, 학사, 장학, 등록, 구매/입찰, 채용] 중에서 선택해주세요."
   - 사용자가 특정 탭을 지시하면 해당 탭 내용만 요약해서 제공해.
   - 반드시 실제 DB에서 가져온 공지사항 데이터를 기반으로 응답해야 하며, 임의 생성은 절대 금지야.
이런식으로 프롬프트가 지금 작성되어 있는데 
먼저 [일반, 학사, 장학, 등록, 구매/입찰, 채용] 이 6개의 탭중 하나를 선택하고 선택한 크롤링된 커뮤니티 데이터를 통해서 그 안에서 나뉜 카테고리를 통해 관련된 공지들을 일정 개수만큼 보여주는거야

기본 제목은 db에서 기본키로 쓰일 예정이야 
그래서 우리가 할일은 [공지 제목]과 각 공지의 링크안에 있는 내용을 크롤링 해서 두가지를 통해 카테고리를 분류하여 실제로 질문시점에 진행중인 내용들을 정리해서 상위 몇개만 말해주는거야
